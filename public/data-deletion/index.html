Solicitação de exclusão de dados

Última atualização: 23 de julho de 2026.

O usuário pode solicitar a exclusão dos dados pessoais mantidos pela Super Educar Brasil.

Como solicitar

Envie um e-mail para admin@supereducarbrasil.com.br com o assunto:

Solicitação de exclusão de dados

Informe no pedido:

  • nome completo;
  • e-mail utilizado no cadastro;
  • telefone utilizado no formulário;
  • descrição dos dados ou cadastro que deseja excluir.

Confirmação da identidade

Poderemos solicitar informações adicionais estritamente necessárias para confirmar a identidade do solicitante e evitar exclusões indevidas.

Processamento

Após a validação do pedido, os dados serão excluídos, anonimizados ou bloqueados, conforme aplicável.

Alguns registros poderão ser mantidos quando necessários para cumprimento de obrigação legal, prevenção de fraude, defesa de direitos ou atendimento de exigência regulatória.

Dados recebidos pelo Facebook e Instagram

O pedido também pode abranger dados enviados por meio de Formulários Instantâneos do Facebook ou Instagram e posteriormente armazenados no CRM.
